# Fair Trade Coffee Blockchain

Ett REST-API byggt med Node.js för att spåra Fair Trade-kaffeleveranser med hjälp av en blockkedja och Proof-of-Work.

## Projektet

Det här projektet är en del av en backenduppgift där Node.js, Express, Vitest och Supertest används.

API:et ska göra det möjligt att registrera kaffeleveranser som transaktioner och lagra dem i en blockkedja som skyddas med Proof-of-Work.
